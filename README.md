
# HTML/CSS Admin Dashboard

This is a standalone HTML and CSS implementation of an educational admin dashboard. This dashboard allows for managing students, teachers, and courses.

## Features

- Responsive design that works on mobile and desktop
- Dashboard overview with key metrics
- Student management page
- Teacher management page
- Course management page with visual course cards
- Navigation between pages
- Search functionality (visual only)
- Mobile-friendly sidebar navigation

## Files

- `dashboard.html` - Main dashboard page
- `students.html` - Student management page
- `teachers.html` - Teacher management page
- `courses.html` - Course management page
- `styles.css` - All styles for the dashboard

## Usage

1. Clone or download these files to your local machine
2. Open any of the HTML files in your web browser to view them
3. You can also edit these files in VS Code or any other code editor

## Customization

You can easily customize this dashboard by:

1. Modifying the colors in the CSS file
2. Adding or removing sections from the HTML
3. Customizing the layout by adjusting the CSS Grid and Flexbox properties
4. Replacing Font Awesome icons with other icon sets

## Notes

This is a static implementation with no backend functionality. In a real-world scenario, you would connect this to a backend server to handle data operations.
